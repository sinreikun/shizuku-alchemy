# 💧 しずく錬金工房 (Shizuku Alchemy)

セル流体シミュレーションで「流れを設計する」パズル ＆ 自由実験室。
**プレイ:** https://sinreikun.github.io/shizuku-alchemy/

## 遊び方
- **チュートリアル・キャンペーン（全12ステージ・7章）** で仕組みを一つずつ学ぶ
  1. 基礎：はじめての導水
  2. 熱と相変化：湯気のエレベーター／溶岩の橋
  3. 密度：油だけ通せ／水銀の重み
  4. 溶解と析出：塩水づくり／塩の結晶
  5. 燃焼：火の番人
  6. 装置と配管：壁の向こうへ（ポンプ）／ふるい分け（選択膜）／電気分解
  7. 循環：水素循環（電解→燃焼→凝縮）
- **自由実験室**：27種類の物質と装置（ヒーター・クーラー・着火器・電解槽・選択膜・ポンプ配管）をすべて最初から使える。ステージで習得した道具には印が付く。
- 資源（インク・装置）を節約するほど ★ が増える。

## 操作
左ドラッグ 描く／右ドラッグ 消す／ホイール 拡大／Space＋ドラッグ・中ボタン 移動／2本指 ピンチ（タッチ）／Space 放水・停止／`.` 1コマ／R 流し直し／Ctrl+Z・Ctrl+Y 戻す・やり直す／`[` `]` ブラシ／F 全体表示

## 反応表（セル数で釣り合う最小の整数比）

数え方：晶塩水＝晶塩＋水、複合結晶＝晶塩＋活性剤、晶塩入り抽出液＝晶塩＋抽出液。どの反応もこの数え方でセル数が保存されます。

### 循環装置（[入口] ＋ [補助入] → [出口] ＋ [補助出]、1回あたり）
| 装置 | 入力 | 出力 |
|---|---|---|
| 電解槽 EL | 水×2（入口） | 水素×1（出口）＋ 酸素×1（補助口） |
| 着火燃焼器 FL | 水素×1（入口）＋ 酸素×1（補助口） | 水蒸気×2（出口、300℃） |
| 凝縮器 CD | 水蒸気×1（入口） | 水×1（出口） |
| 結晶反応器 CR | 晶塩×1（入口）＋ 活性剤×1（補助口、下から吸い上げ） | 複合結晶×1（出口、55℃） |
| 結晶再生器 RG | 複合結晶×1（入口） | 晶塩×1（出口、220℃）＋ 活性剤×1（補助口） |
| 抽出器 EX | 塩水×1（入口、跡に水×1が残る）＋ 抽出液×1（補助口） | 晶塩入り抽出液×1（出口） |
| 回収器 RC | 晶塩入り抽出液×1（入口） | 晶塩×1（出口）＋ 抽出液×1（補助口） |

自由実験室では、各ポートの量（1〜9）と1ティックあたりの処理回数を調整できます（比を崩すとセル数が増減することがパネルに表示されます）。ステージでは既定値で固定です。

### 盤面での反応
| 反応 | 式 |
|---|---|
| 溶解 | 水 ＋ 晶塩 → 塩水（2→1） |
| 塩水の沸騰（100℃） | 塩水 → 晶塩 ＋ 水蒸気（1→2） |
| 状態変化 | 水⇄氷（0℃/2℃）、水⇄水蒸気（100℃/70℃）、揮発溶媒⇄溶媒蒸気（65℃/55℃）、水銀⇄水銀蒸気、溶岩⇄岩石、砂→ガラス（1400℃） |
| 水素の燃焼 | 水素 ＋ 酸素 → 炎×2 → 水蒸気×2 |
| 油・すすの燃焼 | 油（すす）＋ 酸素 → 炎 ＋ 二酸化炭素 |
| 簡易電解板 | 水×1 → 水素か酸素×1（交互、つまり水×2 → 水素×1 ＋ 酸素×1）、塩水 → 晶塩 ＋ 気体 |
| 活性剤の結晶化（90℃未満） | 活性剤 ＋ 塩水 → 複合結晶 ＋ 水 |
| 複合結晶の分解（220℃以上） | 複合結晶 → 晶塩 ＋ 活性剤 |
| 溶岩と水 | 水 → 水蒸気（溶岩は冷える） |

v0.8 で、結晶反応器（旧：晶塩1＋活性剤1→複合結晶2）と結晶再生器（旧：複合結晶2→晶塩1＋活性剤1）を、盤面の反応と同じ比に揃えました。

### 装置の出力（自由実験室で調整可）

ヒーター・クーラー・着火器は、接している気体と強く熱をやり取りします（放熱フィンのイメージ）。気体は熱容量が小さいので、液体や固体の温度にはあまり影響しません。
| 装置 | 既定 | 調整範囲 |
|---|---|---|
| ヒーター | 600℃ | 30〜1175℃ |
| クーラー | -60℃ | -95〜15℃ |
| 着火器 | 900℃ | 300〜1175℃ |
| 簡易電解板 | 10%/接触 | 1〜100% |
| ポンプ | 6セル/ティック・半径4 | 1〜40・1〜12 |

## 開発
```sh
npm install
npm run dev
npm test        # エンジン単体テスト＋全ステージの自動解答検証
npm run build   # dist/ に静的出力
```

| ファイル | 役割 |
|---|---|
| `src/sim.ts` | セル流体エンジン（型付き配列、移動・熱・相変化・反応・装置・ポンプ） |
| `src/game.ts` | ゲーム進行（湧き口・ゴール・手持ち資源・Undo）。DOM非依存 |
| `src/levels.ts` | ステージ定義と自動検証用の解答手順 |
| `src/main.ts` | UI・描画（発光・粒子）・入力・カメラ |

参考: `sinreikun/wind-zest-lake-fjord`（セル流体実験台）、`sinreikun/GPT-FluidLab.tsx`（Fluid Lab）。
